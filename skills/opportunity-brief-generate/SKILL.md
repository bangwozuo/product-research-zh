| 类型 | **`atomic`（原子技能）** |

## 能力描述

数据→结论式周报

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `metrics` | object | ✅ | 经营数据（流水、客流、订单等） |

## 输出规格

报告与简报

- `headline`：一句话结论，先行给出
- `metrics_summary`：本期/上期/变化
- `drivers`：影响结果的主要原因
- `suggestion`：下一步可执行的动作

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "metrics": "店铺「家居收纳旗舰店」周度经营数据：曝光量 本期128万 / 上期110万；访客数 本期14.4万 / 上期12.6万；支付转化率 本期3.2% / 上期3.6%；支付订单数 本期4,608单 / 上期4,536单；支付GMV 本期52.7万元 / 上期48.2万元；客单价 本期114.3元 / 上期106.2元；退货率 本期5.8% / 上期4.9%。备注：本期新增桌面暖风机链接于10-04开售，贡献订单约420单，客单价高于店内收纳类目均值。",
  "period": "2026-09-29 至 2026-10-05（对比上期 2026-09-22 至 2026-09-28）"
}

```

**输出**：

## 核心结论

本期（2026-09-29～10-05）GMV 52.7万元、环比+9.4%，增长由曝光与流量放量驱动，但转化率下滑与退货率上升正在侵蚀增量，需优先修复。

## 关键指标

| 指标 | 本期 | 上期 | 变化 | 说明 |
|---|---|---|---|---|
| 曝光量 | 128万 | 110万 | +16.4% | 类目大盘上行叠加竞品降价带来的搜索流量 |
| 访客数 | 14.4万 | 12.6万 | +14.3% | 与曝光同步增长 |
| 支付转化率 | 3.2% | 3.6% | -0.4pp | 流量质量被摊薄所致 |
| 支付订单数 | 4,608单 | 4,536单 | +1.6% | 订单增长远低于流量增长 |
| 支付GMV | 52.7万元 | 48.2万元 | +9.4% | 新品暖风机贡献约420单 |
| 客单价 | 114.3元 | 106.2元 | +7.5% | 高客单暖风机拉高结构均值 |
| 退货率 | 5.8% | 4.9% | +0.9pp | 需按链接拆分定位来源 |

## 驱动因素

1. 类目热度上行（周环比+18%）与店铺曝光增长（+16.4%）同向，属大盘红利而非店铺独立增长。
2. 新品桌面暖风机 10-04 开售即贡献约 420 单，是订单与客单价的主要增量来源。
3. 转化率 -0.4pp 抵消了部分流量红利：访客 +14.3% 仅换来订单 +1.6%。

## 行动建议

1. 本周完成退货率按链接拆分，定位是暖风机新品（规格预期不符）还是收纳主链接（价格战比价流失）导致，两周内给出整改项。
2. 对暖风机落地页补充功率/噪音/适用面积参数与对比表，观察一周内转化率能否回升至 3.4% 以上。
3. 收纳主链接在 69-75 元竞品价格带内评估小幅促销或赠品策略，人工确认后再执行，避免直接跟进降价。
