> 复合技能 = 工作流。它把多个**原子技能**按业务顺序编排在一起，完成一个完整场景。

## 能力描述

1. **S1 机会简报生成**：解析周度指标（支持 万/%/元/单 单位），百分比类算 pp 变化、数值类算环比%，保留 1 位小数，新品贡献订单原样保留
2. **S2 简报装配**：锚点结论取 GMV（无则订单）变化；TOP2 机会取最大正向项（逆向指标如退货率上升计入风险）；风险清单收录全部负向与逆向上升项，按幅度降序
3. **S3 汇总交付**：执行摘要 + 关键指标表 + TOP 机会 + 风险清单 + 行动建议（每条带量化验收点）；负面指标不得隐去

## 使用步骤

### 方式一：纯提示词编排（跨平台）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供店铺名、周期、指标数据与备注
3. 按 S1 指标计算 → S2 简报装配 → S3 汇总得到周报
4. S1/S2 的变化值与清单用下方脚本实测，不靠模型口算

### 方式二：带脚本（端到端产物）

```bash
python scripts/run_flow.py --input input.json --outdir out
python scripts/run_flow.py --demo
```

## 边界（不做的事）

- ❌ 不编造指标、变化值或归因；不写无数据支撑的结论
- ❌ 不隐去或弱化退货率、转化率下滑等负面指标
- ❌ 不做经营决策承诺；建议只到「动作 + 验收点」
- ❌ 不用模型口算替代脚本计算
- ❌ 不涉及资金操作或代替用户做最终决策

## 调用示例

**输入**（`examples/input.json`）：店铺「家居收纳旗舰店」2026-09-29～10-05
的 7 项周度指标（曝光 128万/110万、GMV 52.7万元/48.2万元、转化率
3.2%/3.6% 等）+ 新品贡献备注。

**输出**（脚本实跑）：S1 计算 7 项变化（GMV +9.3%、转化率 -0.4pp 等）；
S2 装配 TOP2 机会（曝光 +16.4%、访客 +14.3%）与 2 项风险（退货率 +0.9pp、
转化率 -0.4pp）。指标表落 `out/flow_brief.csv`，简报骨架落
`out/flow_report.md`。
