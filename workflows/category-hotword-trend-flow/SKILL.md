## 能力描述

1. **S1 类目趋势采集**：从粘贴材料结构化抽取热词榜 / 海外热帖 / 短视频话题条目，按环比阈值（缺省 +19%）与条数上限（缺省 8 条）筛选，拦截与截断显式报告
2. **S2 趋势标记**：环比 ≥ +30% 标「重点机会」、+19%～+30% 标「观察池」、无量级环比不参与分级
3. **S3 汇总交付**：执行摘要 + 机会清单 + 分步结果，末步带 AI 生成标识；数值以脚本输出为准，入场判断交给下游评分/测算技能

## 使用步骤

### 方式一：纯提示词编排（跨平台）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供粘贴材料与采集范围（时间窗口 / 条数上限 / 环比阈值）
3. 按 S1 采集 → S2 标记 → S3 汇总得到机会清单
4. S1/S2 的数值用下方脚本实测，不靠模型口算

### 方式二：带脚本（端到端产物）

```bash
python scripts/run_flow.py --input input.json --outdir out
python scripts/run_flow.py --demo
```

## 边界（不做的事）

- ❌ 不编造条目、搜索量、环比数据；不虚构来源
- ❌ 不把「重点机会」表述为「必买」「稳赚」——入场判断交给下游
- ❌ 不抓取需登录的私域数据，不绕过平台风控
- ❌ 不跳过趋势标记节点直接给清单
- ❌ 不涉及资金操作或代替用户做最终决策
