## 能力描述

1. **S1 利润测算**：固定拆解顺序（履约成本小计 → 佣金/广告/退货按售价计提 → 单件总成本 → 单件净利 → 净利率 → 月净利），每行带计算式；参数缺失列清单中止
2. **S2 打分卡生成**：净利率 → 利润维度分声明映射（≥25%→90；20~25%→80；15~20%→70；<15%→60），权重 0.5/0.3/0.2，竞争与供应链维度标「待补」并指引补充路径
3. **S3 汇总交付**：执行摘要 + 利润明细 + 打分卡；结论档位：利润分 ≥80 建议推进试单（人工确认）、60~80 谨慎推进、<60 暂缓

## 使用步骤

### 方式一：纯提示词编排（跨平台）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供候选品名称与测算参数（成本项 / 售价 / 月销 / 费率）
3. 按 S1 利润测算 → S2 打分卡 → S3 汇总得到打分卡
4. S1/S2 的数值与得分用下方脚本实测，不靠模型口算

### 方式二：带脚本（端到端产物）

```bash
python scripts/run_flow.py --input input.json --outdir out
python scripts/run_flow.py --demo
```

## 边界（不做的事）

- ❌ 不编造成本、售价、费率或得分；参数缺失不估算、列清单中止
- ❌ 不把打分卡表述为「保证盈利」——不构成资金决策依据
- ❌ 不替用户拍板「上不上」——试单/定价/采购保留人工确认
- ❌ 不用模型口算替代脚本计算
- ❌ 不处理竞争与供应链维度的臆测，一律标「待补」

## 调用示例

**输入**（`examples/input.json`）：候选品「桌面暖风机」——采购价 32 元/件、
头程 6.5 元、尾程 8 元、包装 1.2 元、售价 89 元/件、月销 3,000 件；
佣金 5.5%、广告 12%、退货 3% 计提。

**输出**（脚本实跑）：S1 单件净利 23.05 元（净利率 25.9%）、月净利约
69,165 元；S2 利润维度 90 分（≥25%→90 档），结论「建议推进试单（人工确认
后执行）」，竞争/供应链维度标待补。打分卡落 `out/flow_card.csv`，
报告落 `out/flow_report.md`。
