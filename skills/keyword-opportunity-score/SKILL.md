# 关键词机会评分

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_ecom_06_sk03` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 选品分析师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | ★★★★☆（⑦共用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

搜索量×竞争度→机会分

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `records` | string | ✅ | 打分对象的数据记录 |

## 输出规格

打分与分层

- `scores`：逐条给出各维度分与总分
- `segments`：各层数量与特征
- `assumption`：所用维度、权重与阈值的来源或假设

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 评分明细

| # | 对象 | 维度A | 维度B | 总分 | 分层 |

| 6 | 车载收纳箱 | 21.4（15,000/700） | 82.0（100-18） | 45.7 | B层 |

| 层级 | 数量 | 占比 | 典型特征 | 建议动作 |
|---|---|---|---|---|
| A层（≥60） | 2 | 33.3% | 宠物自动喂食器搜索量大但竞争激烈；折叠收纳箱热度与竞争均衡 | 优先跟进：折叠收纳箱可做差异化卖点；喂食器需先评估对手实力 |

## 假设说明

1. 维度与权重（A=搜索热度 0.6、B=低竞争 0.4）与分层阈值（60/45）为本次执行声明采用的口径，非唯一正解；用户可按自身策略调整权重后重算。
2. 维度A 采用线性归一（搜索量/700，封顶100），意味着 70,000 以上搜索量不再加分；若希望放大大词差异，可改用对数归一。
3. 搜索量为 2026-10 第 1 周数据，季节性关键词（如桌面暖风机）的分数会随取暖季结束回落。
